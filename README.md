# سیستم مدیریت کافه و رستوران ☕

یک وب‌اپلیکیشن کامل و حرفه‌ای برای مدیریت کافه و رستوران با طراحی مدرن، مینیمال و کاملاً فارسی (RTL).

## 🎨 ویژگی‌های طراحی

- **طراحی مدرن و لوکس**: الهام از Apple، Stripe و Linear
- **رنگ‌بندی گرم کافه‌ای**: Primary #C67C4E، Secondary #2D2D2D، Accent #F4B860
- **فونت‌های فارسی**: IRANYekanX و Vazirmatn
- **Dark Mode حرفه‌ای**: تم تاریک کامل با رنگ‌بندی هماهنگ
- **Responsive Design**: عملکرد بی‌نقص در Desktop، Tablet و Mobile
- **Glassmorphism ملایم**: جلوه‌های بصری مدرن و ظریف

## 📱 صفحات پیاده‌سازی شده

### 1. **صفحه Landing** (`/`)
- Hero section جذاب با CTA
- معرفی امکانات با آیکون‌های زیبا
- آمار و نمودارهای تعاملی
- نظرات مشتریان
- تصاویر واقعی کافه از Unsplash

### 2. **احراز هویت**
- **Login** (`/login`): ورود با ایمیل و رمز عبور، Social Login
- **Register** (`/register`): ثبت‌نام با فرم کامل و اعتبارسنجی

### 3. **داشبورد مدیریت** (`/dashboard`)
- کارت‌های آماری (فروش، سفارش‌ها، مشتریان)
- نمودار فروش هفتگی (Bar Chart)
- نمودار توزیع فروش (Pie Chart)
- لیست سفارش‌های اخیر
- پرفروش‌ترین محصولات با Progress Bar

### 4. **مدیریت سفارش‌ها** (`/orders`)
- لیست تمام سفارشات با فیلتر وضعیت
- Tabs: همه، در انتظار، در حال آماده‌سازی، آماده، تکمیل شده
- Timeline و جزئیات هر سفارش
- امکان تغییر وضعیت سفارش
- Badge های رنگی برای وضعیت‌ها

### 5. **مدیریت میزها** (`/tables`)
- Visual Map میزها با رنگ‌بندی وضعیت
- وضعیت‌ها: خالی (سبز)، مشغول (قهوه‌ای)، رزرو (آبی)
- نمایش اطلاعات مشتری و مبلغ سفارش
- آمار کلی میزها
- امکان رزرو و تسویه حساب

### 6. **مدیریت منو** (`/menu`)
- Grid view زیبا با تصاویر محصولات
- دسته‌بندی: قهوه، دسر، نانوایی
- Badge برای پرفروش‌ها و ناموجودها
- افزودن، ویرایش و حذف آیتم‌ها
- تصاویر واقعی از Unsplash

### 7. **POS / صندوق** (`/pos`)
- رابط کاربری Touch-Friendly
- انتخاب سریع محصولات
- سبد خرید تعاملی
- محاسبه تخفیف و مالیات
- پرداخت نقدی و کارتی
- چاپ فاکتور

### 8. **مدیریت مشتریان** (`/customers`)
- سیستم Loyalty و امتیازدهی
- سطوح مشتری: برنزی، نقره‌ای، طلایی، پلاتینی
- تاریخچه خرید و آمار
- Progress Bar تا سطح بعدی
- CRM ساده و کاربردی

### 9. **مدیریت کارکنان** (`/staff`)
- لیست کارکنان با نقش‌ها
- وضعیت: فعال، استراحت، آفلاین
- شیفت‌های کاری
- عملکرد و ارزیابی کارکنان

### 10. **مدیریت انبار** (`/inventory`)
- موجودی مواد اولیه
- هشدار کمبود موجودی (رنگ‌بندی)
- Progress Bar نمایش موجودی
- سفارش خرید مواد

### 11. **گزارش‌ها** (`/reports`)
- نمودار درآمد ماهانه (Line Chart)
- ساعات شلوغی روز (Bar Chart)
- توزیع فروش بر اساس دسته‌بندی (Pie Chart)
- آمار کامل فروش و سود
- قابلیت Export به Excel

### 12. **تنظیمات** (`/settings`)
- اطلاعات کسب‌وکار
- تنظیمات اعلان‌ها
- روش‌های پرداخت
- دسترسی کارکنان
- امنیت و تغییر رمز عبور
- زبان و منطقه

## 🛠 تکنولوژی‌ها

- **React 18.3** - کتابخانه UI
- **React Router 7** - مدیریت مسیریابی
- **Tailwind CSS v4** - استایل‌دهی
- **Recharts** - نمودارها
- **Radix UI** - کامپوننت‌های پایه
- **Lucide React** - آیکون‌ها
- **Next Themes** - Dark Mode
- **Motion (Framer)** - انیمیشن‌ها
